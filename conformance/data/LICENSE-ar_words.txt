This directory contains TWO word lists. They are different sources and both keep their own licence;
this repository's MIT licence does not relicense either.

1. `ar_words_wiki50k.txt.gz` — the shipped lexicon (PR-2 candidate)
   The first 50,000 lines of the Arabic Wikipedia frequency list:
     IlyaSemenov/wikipedia-word-frequency — results/arwiki-2022-08-29.txt

     output sha256 60ee5e67102248111ef87b6f72a8a1f73753c9d01994a98b233eadf6b321df69
   The text is derived from Arabic Wikipedia and is licensed CC-BY-SA-4.0 (attribution: Arabic Wikipedia
   contributors, via IlyaSemenov/wikipedia-word-frequency). Wikimedia's dump licence
   page (https://dumps.wikimedia.org/legal.html, retrieved 2026-11-24) states that all original textual
   content is under CC-BY-SA-4.0 (and GFDL). The source file is a 2022-08-29 dump; the version in force
   on that historical date is not independently verified here — the notice reports the official page's
   current statement, and the package's SPDX expression names 4.0. The repository that publishes the list
   is MIT. Filtering: only the word field of each source line; the first 50,000 lines; gzip with mtime=0.
   No other change. The build is `scripts/build_wiki_lexicon.py` (both digests are constants it verifies).

2. `ar_words_50k.txt.gz` — the PR-2 baseline
   FrequencyWords — Arabic 50k list (2018):
     https://github.com/hermitdave/FrequencyWords
     built from OpenSubtitles 2018 (http://opus.nlpl.eu/OpenSubtitles2018.php)
   MIT License for the code; CC-BY-SA-4.0 for the content. This repository keeps the content under
   CC-BY-SA-4.0 (attribution: FrequencyWords / OpenSubtitles 2018). Filtering: only Arabic-script entries
   of 3 or more letters, deduplicated and sorted.

Both files are read at runtime by `conformance/checks/lexical.py`; they are never written to. The first is
the default (`DATA`); the second is `CURRENT_DATA`, retained so the comparison in
`docs/checker-v0/08-pr2-evidence-2026-11-24.md` can be re-run. If the comparison says the candidate is not
better, the default returns to the baseline and the candidate is not merged.
