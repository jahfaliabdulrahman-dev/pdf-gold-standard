# Check inventory — the 38 checks of `scripts/verify_pdf.py`

Every check in `verify_pdf.py` carries a kind in `verify_pdf.CHECK_KIND`, and the kind is printed on its own
line (`PASS pages [calibrated] - 12 (expected 12)`). A check with no kind is a **failure**, not a warning:
`make_checker` refuses it by name, and `scripts/test_check_kinds.py` proves that refusal with a check that
passes its comparison but declares no kind.

- **generic** — reads no constant of a document's spec: no expected ink, footer value, slot position, link or
  field count, no calibrated floor. It would hold on a file this repository never saw.
- **calibrated** — reads at least one such constant, so its verdict is about *this* document. A check that
  mixes both is calibrated, and its generic part is named below as a candidate to move into `conformance/`.

The table is generated by hand from the code, and `scripts/test_check_kinds.py` holds it to the code in both
directions (no missing row, no extra row, no drifting name). Row count is derived from `CHECK_KIND`.

## Candidates to move into the public gate

Each is a generic rule currently living inside a calibrated check. None of them moves in this cycle
(Path C builds its own package); they are listed so the next cycle does not rediscover them:

1. `pdfua`'s structure floor (ParentTree resolves each `/StructParent`, `/MarkInfo`, `DisplayDocTitle`,
   every structure element has a `/P`).
2. `tagged`'s structure-tree presence.
3. `xmp`'s four presence fields.
4. `no-blank-pages`' blank rule (median text + image excuse), which needs no document constant.
5. `acroform`'s field contract, `link-tagging`'s per-link contract.

## How this table is held to the code

```bash
.venv/bin/python scripts/test_check_kinds.py
```

It derives the check set from `spec_base.CHECK_NAMES` (not from this file), requires set equality with
`verify_pdf.CHECK_KIND`, requires one table row per name, and proves the no-kind guard by passing a check
that succeeds but has no kind — the gate must still name it as a failure.
