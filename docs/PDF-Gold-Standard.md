## 1) نظام التنقل التفاعلي (الميزة الأهم المفقودة عندنا سابقاً)

### أزرار التنقل الثابتة — على كل صفحة محتوى (ص 4–35)
- **أربعة أزرار 25×25pt** في صف أفقي أعلى الصفحة:
  - `x=58pt` ← **التالي** (سهم يسار — منطق RTL: التالي نحو اليسار)
  - `x=95pt` → **السابق**
  - `x=133pt` ≡ **جدول المحتويات**
  - `x=170pt` ⌂ **الغلاف/الرئيسية**
- التباعد: 37–38pt بين الأزرار · الموضع العمودي: y=37–62pt (أعلى الصفحة)
- **الأيقونات تتلون حسب الخلفية**: بيضاء على الصفحات الداكنة، بنفسجية (#6d3ff0) على الفاتحة
- الوجهات **Named Destinations** — تصمد حتى لو تغيّر ترقيم الصفحات
- الاستثناءات: الغلاف (بلا أزرار)، صفحة البسملة (بلا أزرار لكن بها تذييل)، الفهرس (بلا أزرار — هو المحطة)، الغلاف الخلفي

### الفهرس الجانبي (Bookmarks)
- 3 مستويات: قسم رئيسي (L1) → أقسام (L2) → عناوين المحتوى (L3)
- يعمل في شريط التنقل الجانبي لأي قارئ PDF

### الفهرس الداخلي (ص 3)
- 6 روابط صفوف كبيرة (351pt عرضاً) → تنقل مباشر لفواصل الأقسام

### الروابط الخارجية + QR
- 11 موقعاً رسمياً: sdaia · dga · mcit · monshaat · gartner · ibm · uipath · zapier · make · hbr · lucidchart
- **بطاقات QR بنفسجية** بجانب كل مرجع/أداة (جسر للجوال)
- أيقونة رابط ↗ صغيرة (بنفسجية) بجانب كل اسم

### عناصر الهوية الفنية
- **خلفيات كونية**: تدرج داكن + جزيئات متلألئة + شعاع ضوئي من الأعلى
- **فن زجاجي ثلاثي الأبعاد موحد**: طبقات زجاج شفافة بنفسجية (لوحات، مكعبات، أيقونات رمزية) على منصة متوهجة — نظام رسومي واحد يتكرر بثبات في الغلاف والفواصل وأيقونات المحتوى
- **كبسولات مائلة**: شريحة مستطيلة بنفسجية مائلة (≈‎-15°) تحمل كلمة من العنوان أو (Automation)
- **كلمات مميزة بالألوان**: داخل العناوين والنصوص (بنفسجي `#b596fd` على الداكن، بنفسجي على الفاتح)
- **شرائح تيل للترقيم**: (أولًا / ثانيًا) في كبسولة تيل بأطراف مدورة
- **شرائح حروف تيل**: أ: ب: ج: بمربعات تيل صغيرة للقوائم

## 4) مكونات الصفحة (المكتبة المرئية)

1. **بطاقات معلومات** (3 في صف): خلفية فاتحة بنفسجية `~#f3f0fb`، عنوان بنفسجي، رمز توضيحي صغير، وصف
2. **بطاقات عريضة** (2 في صف) للمفاهيم الطويلة
3. **خط زمني بعمودين** (ص 8): عمودان يمين/يسار حول محور رأسي، عقد مربعة على المحور، أرقام عربية-هندية ١–١٠، أيقونة زجاجية لكل محطة
4. **شريط أدوات بنفسجي عريض**: عنوان أبيض + شعارات أدوات + أيقونة فتح — روابط حية
5. **بطاقة QR فوق صورة**: كارت بنفسجي مدمج بزاوية الصورة، عنوان + QR + أيقونة سهم منحنٍ
6. **قائمة مراجع**: صف لكل مرجع = QR يسار + أيقونة ↗ + اسم يمين، خطوط فاصلة رفيعة بنفسجية
7. **فواصل الأقسام**: صفحة كاملة فنية (عنوان + كبسولة مائلة + عمل زجاجي كبير + منصة متوهجة) بلا تذييل
8. **الجداول والقوائم**: عناوين بأشرطة، قوائم نقطية، صناديق ملاحظات

## 5) الإيقاع الطباعي (خريطة الثيمات — تصميم متعمد)

- **داكنة**: الغلاف · البسملة (فاتحة بيضاء فنية) · الملخص والمقدمة · الفواصل الستة · صفحات قفصلية (قصة نجاح ص16، مبدأ باريتو ص19، الحوكمة ص30، المستقبل ص32، الخاتمة ص33) · الغلاف الخلفي
- **فاتحة**: صفحات المحتوى العادية (المعظم)
- التنقل بين الثيمات يخلق **إيقاعاً مسرحية**: كل قسم يفتح بمشهد داكن ثم يتنفس في صفحات فاتحة
- خريطة الصفحات المقيسة (luminance): DARK: 1,4,5,7,8,11,16,17,19,24,28,30,32,33,34,36 · LIGHT: rest

## 6) دعم العربية والنسخ

- تشكيل كامل واتجاه RTL سليم في كل الطبقات
- **طبقة نص Unicode**: النص يُحدد، يُبحث، ويُنسخ — قابل للتحقق بـ pdftotext
- خلط عربي-لاتيني مدروس (الأقواس، الاختصارات الإنجليزية داخل النص العربي)
- أرقام: عربية-هندية للمحتوى، لاتينية للتذييل
- المحاذاة: فقرات مضبوطة (justified) بمحاذاة يمين
- ملاحظة: الشبكة: هوامش L/R = 61pt/60pt (≈21.5مم) · عرض المحتوى 474pt · التذييل عند y≈805–813

## 8) فحص الفجوة — ماذا نملك وماذا ينقص

### ✅ متوفر لدينا (جاهز)
| القدرة | الأداة |
|---|---|
| تصميم HTML/CSS كامل RTL + طباعة PDF | Chrome headless `--print-to-pdf` (مجرّب) |
| **أزرار تنقل + فهرس جانبي + روابط** | **PyMuPDF: set_toc + insert_link (PROVEN 13/09)** |
| تثبيت تذييل + ترقيم دقيق لكل صفحة | توليد الصفحات في Python (كل صفحة div بالرقم) |
| QR codes | Python qrcode / segno |
| مخططات احترافية (BPMN/مخططات) | مهارة diagram-design |
| توليد فن زجاجي ثلاثي الأبعاد | ComfyUI (يُختبر) أو CSS 3D |
| خطوط عربية احترافية | IBM Plex Sans Arabic (Google Fonts — نفس العائلة!) |

### ⚠️ فجوات معروفة (مقبولة/لها بدائل)
1. **Tagged PDF (الوصول لذوي الاحتياجات)**: InDesign يصدّر بنية وصول — Chrome لا. بديل عند الحاجة: WeasyPrint أو إضافة لاحقة.
2. **الفن ثلاثي الأبعاد**: نولّده (ComfyUI) أو نبنيه CSS — يحتاج هوية أسلوب ثابتة.
3. **الكشيدة الزخرفية المثالية**: InDesign يعالجها ببراعة — عندنا: إدراج حروف الكشيدة (ـ) يدوياً في العناوين المختارة.

## 9) سلسلة الإنتاج المعتمدة (المعيار التنفيذي)

```
1. البنية: خريطة الصفحات (داكن/فاتح) + قائمة المكونات
2. الهوية: اللوحة + الخطوط + الفن (توليد) + الأيقونات
3. البناء: HTML مُولّد من Python (كل صفحة div مستقل بمعرف)
   - أزرار التنقل مرسومة في كل صفحة عند (58/95/133/170pt, 37pt)
   - تذييل + رقم صفحة مكتوبان في كل div
4. الطباعة: Chrome headless --print-to-pdf
5. التفاعل: PyMuPDF → set_toc (الفهرس) + insert_link (الأزرار + روابط الفهرسمجلة + الخارجية)
6. التحقق: قراءة عكسية get_toc/get_links + فحص مواضع + تدقيق بصري
7. التسليم: MEDIA + اختبار ضغط فعلي
```

## 10) قرارات المعيار (غير قابلة للتفاوض في مخرجاتنا)

1. أي مستند > 4 صفحات: **يخضع لهذا المعيار كاملاً** (أزرار + فهرس جانبي على الأقل)
2. عائلة خط واحدة بأوزان متعددة — لا خلط عائلات
3. تبادل داكن/فاتح لكل مستند طويل
4. كل رابط = رابط حي (لا نصوص جامدة)
5. ترقيم عربية-هندية للمحتوى
6. تذييل متحرك: عنوان المستند + وصفه + رقم الصفحة
7. التحقق الآلي قبل أي تسليم: get_toc + get_links + bbox checks
